# Chaps Gym

An offline-capable personal training app with adaptive scheduling, workout logging, rest timers, conditioning and encrypted backup files.

## Publish

Upload the docs folder into the root of a public GitHub repository. In Settings → Pages, select Deploy from a branch, main, /docs, then Save. No custom domain or paid service is needed.

## Install on iPhone

Open the published link in Safari, then Share → Add to Home Screen. Open the installed app online once and wait for Offline ready. Complete setup on your phone; no personal records are seeded in these files.

## Privacy and backup

Workout and recovery records stay in this browser’s local database. The app has no trackers or workout-data server. Local records are not separately encrypted at rest. Encrypted backup exports use a passphrase you keep; it cannot be recovered. Verify downloaded files and copy them into iCloud Drive manually if desired. Clearing browser storage or losing the phone can lose records. Background timer alerts cannot be guaranteed on iPhone.

The app is training assistance, not a diagnosis. Severe symptoms block training recommendations.

The complete development source and tests remain in the original local project folder.
